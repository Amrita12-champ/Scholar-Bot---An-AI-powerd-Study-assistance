# 🎓 ScholarBot

**ScholarBot** is an AI-powered research and academic assistant designed to streamline literature review, paper summarization, citation tracking, and Q&A over academic publications.

---

## ✨ Features

- **Semantic Literature Search:** Query arXiv, Semantic Scholar, and OpenAlex using natural language.
- **RAG-Powered Paper Q&A:** Chat directly with uploaded PDFs or fetched research papers with page-level citations.
- **Automated Summarization:** Generate abstract-level summaries, key contributions, methodologies, and limitation breakdowns.
- **BibTeX & Citation Management:** Export properly formatted citations (APA, MLA, IEEE, BibTeX) with a single click.
- **Multi-Modal Support:** Parse and explain complex figures, tables, and equations from technical papers.

---

## 🛠️ Tech Stack

- **Core Engine:** Python 3.10+, LangChain / LlamaIndex
- **LLMs & Embeddings:** OpenAI GPT-4o / Claude 3.5 Sonnet / Hugging Face Embeddings
- **Vector Database:** ChromaDB / FAISS / Qdrant
- **Parsing:** PyMuPDF, Unstructured, Nougat
- **Interface:** Streamlit / FastAPI + React
